# 评测与晋升协议

在定义实验门槛、估计噪声、决定官方提交或晋升基线时读取本文件。

## 一、指标契约

每个比赛先在 `00_先看这里.md` 明确：

```yaml
primary_metric: <名称>
direction: maximize | minimize
unit: <单位>
hard_constraints:
  - <正确性、资源、时限、规则等>
minimum_practical_improvement: <最小实际收益>
noise_method: <固定重复、配对运行、多随机种子、bootstrap 等>
replicates: <按成本和风险决定>
aggregation: mean | median | percentile | worst_case
evaluation_command: <可复现命令>
official_validation_required: true | false
```

指标契约变化属于实质事件，需要写笔记解释原因，不能在看到候选结果后偷偷移动门槛。

## 二、本地评测与官方提交分离

### `notes/_evaluations.md`

记录本地、离线或可重复评测：

- 运行 ID、日期、commit/快照、环境和数据版本。
- 基线/候选关系、随机种子和精确命令。
- 主指标、约束指标、聚合方法和原始产物路径。
- 是否有效及无效原因。

### `notes/_submissions.md`

只记录真实官方提交：

- 提交 ID、commit/快照、提交配额影响。
- 公开榜、私榜或最终评测结果。
- 与本地预期的差异和后续判断。

除非官方评测明确随机、提交额度充足且重复提交本身符合策略，不要为了估计方差重复提交同一产物。

## 三、重复次数与噪声

不要把“重复 2-3 次”写成普遍定律：

- 确定性评测：环境和输入相同应得到相同结果；重复主要用于发现环境漂移。
- 随机训练或随机评测：使用多个预先声明的种子，报告分布而非只报最好一次。
- 昂贵系统评测：优先 A-B-A、交错运行或配对差值，减少时间漂移影响。
- 数据型指标：可使用 bootstrap、交叉验证或分层切分，但要防止测试集泄漏。
- 稳定性目标：报告尾延迟、失败率、最差值或连续成功次数，而不只看均值。

运行次数由噪声、成本和决策风险共同决定。证据不足时结果是 `inconclusive`，不是自动失败。

## 四、对照设计

优先保证基线和候选只在目标变量上不同，并共享：

- 数据版本、预处理和采样策略。
- 构建产物、依赖、硬件和运行参数。
- 预热策略、缓存状态和测量窗口。
- 指标实现和结果解析脚本。

因果实验无法单变量时，说明不可拆分原因，并把整个改动集作为一个候选。组合候选不能直接继承成员实验的收益结论。

## 五、结果分类

- `pass`：评测有效，满足方向、硬约束、噪声余量和最小实际收益。
- `fail`：评测有效，但未过预先门槛。
- `inconclusive`：证据不足、结果冲突或置信度不足。
- `invalid`：命令、环境、数据或指标计算使结果不可用于决策。
- `pending`：仍在运行或等待正式结果。

只有 `fail` 才能据此关闭路线；`invalid` 修复评测后重跑，`inconclusive` 补充最有信息量的证据。

## 六、晋升规则

最大化指标可使用：

```text
candidate - baseline >= max(noise_margin, minimum_practical_improvement)
```

最小化指标可使用：

```text
baseline - candidate >= max(noise_margin, minimum_practical_improvement)
```

同时要求全部硬约束通过。噪声余量可以来自配对差值分布、置信区间、历史稳定区间或赛制明确给出的容差，但必须记录计算方式。

多目标项目需要预先声明：

- 主指标优先，次级指标只设不可退化约束。
- 加权目标，权重在实验前固定。
- Pareto 决策，由用户在多个非支配候选间选择。

不要把“分数更高”当作所有比赛的默认晋升条件。

## 七、官方结果偏差调查

官方结果与本地预期不一致时依次检查：

1. 提交产物是否对应记录的 commit、配置和数据。
2. 本地与官方指标定义、方向、切分和预处理是否一致。
3. 是否存在公开榜/私榜差异、隐藏约束或分布偏移。
4. 本地噪声模型是否覆盖当前差异，样本是否足够。
5. 是否出现真实回归、缓存污染、环境漂移或数据泄漏。

在原因未明时标记 `inconclusive`。不要因为差异“看起来像噪声”就禁止调查，也不要因为一次异常就立即改代码。
