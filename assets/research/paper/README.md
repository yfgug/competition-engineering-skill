# 论文状态入口

- 研究类型: reproduction / exploratory / confirmatory / competition-to-paper
- 目标 venue/交付形式: <会议、期刊、技术报告或复现报告>
- 当前阶段: <实验设计 / 实验 / 分析 / 写作 / 冻结 / 投稿>
- 论文版本: <commit / 文档版本>
- 核心 claim 矩阵: `CLAIMS.md`
- 图表与表格台账: `ARTIFACTS.md`
- 数据说明: `../data/README.md`
- 最新实验笔记: `../notes/YYYYMMDD_NN_xxx.md`
- 下一步唯一动作: <一句话>

正文中的结论强度不得超过 `CLAIMS.md` 的证据状态。
