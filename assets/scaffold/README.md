## 目录导览

- `00_先看这里.md` — 唯一入口（人与 AI 都从这里进）
- `notes/` — 持久化实验笔记（唯一事实源）
- `scripts/` — 全部脚本（命名自索引）
- `results/` — 实验结果归档
- `backups/` — 基线快照（zip + SHA256）
- `source/` — 比赛源码（git 管理）
- `deliver/` — 交付物（只留当前推荐版）
- `archive/` — 已关闭方向与旧版本归档

## 协作方式

AI 执行前先读 `00_先看这里.md` 与 `AGENTS.md`；一切结论落盘到 `notes/`。
