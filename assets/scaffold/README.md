## 目录导览

- `00_先看这里.md`：唯一动态入口、指标契约和当前状态
- `AGENTS.md`：稳定红线、权限和环境约束
- `notes/`：实验笔记、本地评测、外部提交和关闭路线
- `scripts/`：可重复执行的脚本
- `results/`：原始评测产物和复现摘要
- `backups/`：必要的离线灾备快照
- `source/`：比赛源码
- `deliver/`：当前待交付物
- `archive/`：历史交付和停止维护的材料
- `tmp/`：可删除临时文件

当前推荐和下一步只维护在 `00_先看这里.md`，历史记录由 `notes/README.md` 索引。
研究 profile 还会创建 `paper/` 和 `data/`，用于 claim、图表以及数据/模型来源追踪。
